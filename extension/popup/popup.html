Troubleshooting & Fixes Linux

If the server is offline, start the background service:

systemctl --user restart yt-dlp-server

Or check service status & logs:

systemctl --user status yt-dlp-server

Run the Windows setup script in PowerShell:

install.bat

Or launch background server directly:

pythonw.exe "%LOCALAPPDATA%\yt-dlp-bridge\server.py"
